PairVC: real-time voice conversion, 20 ms at a time

A small, fully causal neural network that turns speech into a target voice while you speak. It learns from paired data: the same speech already converted by a big, slow "teacher" model, which it learns to reproduce at a fraction of the cost.

Try it in your browser

The trained demo model (3 MB ONNX file) runs here, on your device, with onnxruntime-web: no server, nothing is uploaded. Like StreamVC, audio goes through the model in 20 ms chunks, and the model keeps a memory of the past between chunks.

Set your expectations: this demo model is small (0.67M parameters) and was trained for 1.5 h on a CPU, on people saying the digits "zero" to "nine". It has learned each voice's timbre, but not yet clean pitch, so the output sounds breathy. Digits work best.

How it works

  1. Make pairs, once and offline. A big, slow teacher model converts many source clips into each target voice, which gives the same speech in two voices.
  2. Train the student. PairVC learns to turn the source into the teacher's output, sample for sample. It is trained as a GAN: a multi-scale mel loss plus HiFi-GAN-style discriminators.
  3. Stream. A causal encoder compresses each 20 ms of audio (320 samples) into one 64-number frame. A mirrored decoder rebuilds the waveform in the target voice, steered by a speaker embedding (FiLM). The model only looks 40 ms ahead, so the voice comes out 60 ms late.
  4. Ship. One ONNX file converts one chunk and passes its memory (state tensors) on to the next call. This page runs exactly that loop.

Code, training (CPU, GPU, multi-GPU, Kaggle notebook), metrics and a Streamlit app are on GitHub.
